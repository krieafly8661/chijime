# ちぢめ
**遊ぶ：** https://krieafly8661.github.io/chijime/

下にスワイプして、身長1.6mから 10⁻³⁵ m（プランク長）まで縮むゲーム。

途中で、猫、1円玉、ミツバチ、髪の毛、赤血球、ウイルス、DNA、水分子、原子核、陽子とすれ違います。どれも本当の大きさです。通りすぎるものをタップすると、名刺がもらえます（全23種）。

そして 10⁻¹⁹ m より先の16桁には、何もありません。今の実験で確かめられたものが、そこには何もないからです。

## 操作
- 下にスワイプ（PCはマウスホイールか ↓ キー）で縮む
- 上にスワイプで少し戻る
- 右下のボタンでも縮める

## 大きさの出典について
大きさは代表的な値です（例：赤血球の直径は約7.5μm、水素原子の直径は約0.1nm、陽子の直径は約1.7fm）。クォークと電子は大きさが見つかっていないため、今の実験で探れるおよその限界（10⁻¹⁹ m）に置いています。
